## 1. Citation Audit Methodology

In high-stakes regulatory RAG systems, citations must be traceable to exact physical document pages to enable human auditability. Every citation generated by the pipeline was audited across four distinct validation gates:
1. **UUID Syntax Validity:** Is the cited passage ID a well-formed RFC 4122 Version 4 UUID?
2. **Passage Existence in Corpus:** Does the cited UUID exist in the authoritative database table `passages`?
3. **Authoritative Page Accuracy:** Does the page number indicated in the citation match the actual `page_number` in the database for that passage?
4. **Semantic Support Rate:** Does the passage referenced by the citation semantically entail the claim it is attached to?

All 111 individual citation records (54 from Config A and 57 from Config B) are recorded in [backend/data/experiments/m10/m10_phase_h_citation_audit.csv](file:///c:/Users/anish/Desktop/IndicRAG-QA/backend/data/experiments/m10/m10_phase_h_citation_audit.csv).

## 4. Analysis of the Page Number Boundary Discrepancy

Across both configurations, exactly **one citation** failed exact page verification:
- **Query ID:** `M9-Q053` (English)
- **Question:** *"Who conducts grade moderation at Bennett University and who approves the final grades?"*
- **Cited Passage ID:** `018a0c03-a8cb-46c1-a787-00875eb20a6a`
- **Document:** `SEAS-Ordinance-Rules-Regulations-2017.pdf` (UUID: `b6f9aad0-4cbd-4915-bc0b-262e14b6e3a2`)
- **Reported Cited Page:** Page 24
- **Actual Database Page:** Page 23

### Root Cause Analysis
During ingestion in Milestone M2, chunking across page boundaries created a parent-child passage that spans the bottom of Page 23 (where Section 27 *Grade Moderation Committee* begins) and the top of Page 24 (where the final submission clause ends). The passage metadata in SQLite assigned `page_number = 23`, whereas the generation model referenced Page 24 where the second half of the paragraph appeared.
- **Severity:** Low. The passage content itself is completely accurate, and the physical text spans across pages 23–24.
- **System Impact:** Semantic support is $100\%$; no factual error was conveyed to the user.
