About IndicRAG-QA

IndicRAG-QA is an evidence-grounded cross-lingual question answering system for university students.

Institutional Integrity Guarantees:

  • Grounded Citations: Answers explicitly cite official documents, clauses, and page numbers.
  • No Guessing: If an academic policy is not documented, the system returns a safe abstention.
  • Language Inclusivity: Accepts questions in English, हिंदी, Romanized Hindi, and Hinglish.

Backend powered by FastAPI, SQLite, BM25 + FAISS Hybrid Fusion, and local Ollama inference.
